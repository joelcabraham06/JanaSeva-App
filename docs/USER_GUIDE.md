# 📱 User Guide (WhatsApp Assistant)

## First Interaction & Language Choice
When a user sends their first message to Janaseva on WhatsApp (or types `Hi`/`Language`):
```
🙏 Janaseva - Government Service Assistant
ജനസേവ സ്വാഗതം! നിങ്ങളുടെ ഭാഷ തിരഞ്ഞെടുക്കുക:

Welcome! Choose your preferred language:
[1. മലയാളം (Malayalam)]
[2. English]
```

## Sample Queries

### 1. Manglish Query
User: `license puthukkanam`
Janaseva Response:
```
🏛️ ഡ്രൈവിംഗ് ലൈസൻസ് പുതുക്കൽ
കേരള മോട്ടോർ വാഹന വകുപ്പ് നൽകിയ ഡ്രൈവിംഗ് ലൈസൻസ് പുതുക്കൽ സേവനം.

📋 ആവശ്യമായ രേഖകൾ (Required Documents):
• നിലവിലെ ഡ്രൈവിംഗ് ലൈസൻസ് (Mandatory)
• ഫോറം 1A മെഡിക്കൽ സർട്ടിഫിക്കറ്റ് (Mandatory)
• പാസ്‌പോർട്ട് സൈസ് ഫോട്ടോ (Mandatory)
• ആധാർ കാർഡ് (Mandatory)

💰 അപേക്ഷാ ഫീസ് (Fees): ₹450 + Portal charges
⏱️ പ്രോസസ്സിംഗ് സമയം (Time): 7 days / ദിവസങ്ങൾ
🏢 ഓഫീസ് (Office): Sub RTO / Akshaya Center
🌐 ഔദ്യോഗിക വെബ്സൈറ്റ് (Website): https://parivahan.gov.in
```

### 2. Document Readiness Checker
User clicks `Checklist` or types `രേഖകൾ`:
```
📋 Document Readiness Check (1/4)
നിങ്ങളുടെ പക്കൽ താഴെ പറയുന്ന രേഖയുണ്ടോ?

👉 നിലവിലെ ഡ്രൈവിംഗ് ലൈസൻസ്
[ഉണ്ട് (Yes)] [ഇല്ല (No)]
```
After answering all questions:
```
✅ നിങ്ങൾ അപേക്ഷിക്കാൻ തയ്യാറാണ്! (Ready to Apply)
```
