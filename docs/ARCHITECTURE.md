# 🏗️ Janaseva System Architecture & Design

## Overview
Janaseva is designed as an enterprise-grade, scalable platform for government information assistance via WhatsApp. The architecture prioritizes data accuracy, multi-lingual parsing, security, and high availability.

## AI Guardrails & Hallucination Prevention Pipeline

1. **Query Parsing**: The user's text or voice input is passed to `ai_service.py` to identify:
   - Language (`ml`, `en`, or `manglish`)
   - Intent mapping (`renew driving licence`, `passport`, etc.)
2. **Database Querying**: The resolved intent is queried against the authoritative PostgreSQL database in `search_service.py`.
3. **Fact Sanitization**: The database record is sanitized using `app/core/guardrails.py`, formatting the exact verified documents, fees, official URL, and guides into the response.
4. **Zero Generation Guarantee**: No factual claims (fees, URLs, procedures) are generated by Gemini. All facts are injected directly from PostgreSQL database columns.
