# 📖 Non-Technical Admin Guide

Janaseva provides a simple React Web Dashboard for managing government service records without writing code.

## Accessing Dashboard
1. Open Admin URL (e.g. `http://localhost:3000`).
2. Login with credentials (`admin` / `janaseva123!`).

## Adding a New Government Service
1. Click **Services Catalog** in sidebar.
2. Click **+ Add Government Service**.
3. Fill in English and Malayalam names, descriptions, fees, processing days, and official portal URL.
4. Enter Manglish search keywords (e.g., `license puthukkanam`, `dl renewal`).
5. Add mandatory documents under **Required Documents**.
6. Click **Save Service**. The service is immediately live on WhatsApp!

## Checking Failed Searches
1. Click **Analytics** in sidebar.
2. Review **Unresolved / Failed Searches** table to discover services citizens are searching for that are not yet added.
